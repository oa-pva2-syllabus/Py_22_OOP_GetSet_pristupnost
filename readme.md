# PVA2 - Programování a vývoj aplikací
## Lekce 22: OOP - Gettery/Settery, Modifikátory přístupnosti

## Obsah

Zkopírujte si do repozitáře své hotové řešení z minulého cvičení, na které dneska navážeme.

Zapracujte do svého programu
- Pro všechny atributy nastavte modifikátor přístupnosti.
- Sestavte settery s vhodnou validací dat pro všechny property.
- gettery tak, aby nikde nebyl volán atribut napřímo. Přístup na všechny atributy bude výhradně přes gettery.
